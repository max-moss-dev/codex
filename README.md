# Aquaglass-1

A more polished satirical single-page website for an unnecessarily sophisticated glass of water, inspired by high-drama AI product launches while using original copy, CSS artwork, and interactions.

## Highlights

- Oversized cinematic hero with an animated CSS glass, scanline, glowing labels, and product-console overlay.
- Interactive hydration lab with a live water-level slider and a hidden sip-note toggle.
- Rich sections for fake benchmarks, feature cards, reviews, model tiers, and a paper-style citation block.
- Fully static HTML/CSS/JS with no build step.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
